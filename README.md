# pingwin

**pingwin** is an open-source Android client for VLESS connections, powered by [sing-box](https://github.com/SagerNet/sing-box).

The project focuses on simple connection management, flexible routing, and automation.

## Features

- VLESS connections, including Reality
- Import connections from VLESS links
- QR code scanner
- Per-app routing
- Website and domain routing
- Network-based automation
- MacroDroid integration
- Diagnostic logs
- English and Russian interface
- Powered by sing-box

## Requirements

- Android 7.0 (API 24) or newer

## Building from source

The repository includes the required `libbox.aar`.

Build the debug APK with Gradle.

## Project information

- Package: `com.pingwin.vpn`
- Current version: `0.1.0`
- sing-box/libbox: `1.13.12`

## Servers

pingwin is a client application. It does not provide servers, subscriptions, or connection credentials.

To use pingwin, you need your own compatible VLESS connection configuration.
